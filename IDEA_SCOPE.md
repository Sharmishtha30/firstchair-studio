No additional AI API key or image credits are required: use the existing connected ChatGPT plan for writing, and render typography-led PNGs in code.

Preserve feedback on one selected piece, source checks, six-image/caption ZIP downloads, reload and mobile use. Prove the end-to-end flow on three different websites. Public-page access or absent brand assets can limit extraction; never claim universal pixel-perfect brand matching. Keep GitHub and Convex, small local commits and no deployment.
